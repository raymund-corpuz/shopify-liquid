# 🛍️ Shopify + Liquid Theme Development

A custom Shopify theme built using **Shopify Liquid**, **HTML**, **CSS**, and **JavaScript**.  
This project is a hands-on exploration of how Shopify themes work — including structure, sections, snippets, and dynamic content using Liquid templating.

---

## 🚀 Features

- 🎨 **Fully Customizable Layout** using Liquid templates and JSON schemas  
- ⚙️ **Dynamic Sections** built for Shopify Online Store 2.0  
- 🌍 **Multi-language Support** through the `locales` folder  
- 💾 **Theme Settings** via `config/settings_schema.json`  
- 🧱 **Reusable Snippets & Blocks** for modular design  
- 🧰 **Shopify CLI Integration** for local development and live preview  

---

## 🧩 Folder Structure

```bash
.
├── assets/        # CSS, JS, and image files
├── blocks/        # Individual reusable content blocks
├── config/        # Theme configuration and customization data
├── layout/        # Main layout (header, footer, etc.)
├── locales/       # Translation JSON files for multi-language support
├── sections/      # Customizable content sections
├── snippets/      # Reusable mini templates (e.g., product-card)
└── templates/     # Page-level templates (e.g., product, index, collection)
